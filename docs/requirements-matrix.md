## Профильная техническая задача

Приложение не сводится к CRUD. Оно читает накопительную статистику PostgreSQL, нормализует SQL, объединяет версии запросов по fingerprint, рассчитывает токсичность вычислений и её физико-экономический эффект. Для демонстрации без внешней инфраструктуры включён детерминированный набор из 56 снимков запросов за семь дней.

## Что заполняет автор

Перед сдачей нужно указать в `.env` ФИО, группу и учебное заведение, контакт, даты работ и при необходимости описание опыта. Секретные ключи и демонстрационные пароли также должны быть заменены.
